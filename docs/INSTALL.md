# Mac 安装与使用

使用 Microsoft 365 桌面版 Word、PowerPoint 或 Excel。安装包已包含所需运行环境和组件，无需另装 Python、Node.js 或开发工具。请保持联网，并准备自己的模型 API Key。

1. 打开下载的 `.pkg` 安装包，完成安装。
2. 在“应用程序”打开 Trojan AI for Office，按提示完成初始化及本机证书信任。
3. 保存文件，完全退出并重新打开 Office，在“开始 → 加载项”找到插件。
4. 在插件设置里选择模型服务，填写自己的 API Key 并选择模型。费用由所选模型服务收取。

安装包尚未完成 Apple 开发者签名与公证。若系统拦截，请保留提示并通过 Issues 反馈；公司电脑请遵循公司的管理要求。

## 选择修改模式

- **只读建议**：先分析和讨论，不修改文件。
- **审核后修改**：需要确认的修改先提出建议，由你采用或拒绝。部分低影响格式操作和空白位置写入可直接执行。
- **直接修改**：按你的要求执行修改，适合已经确定要做的任务。

聊天中说“直接改吧”不会自动切换模式。如果想让它直接执行，请在界面切换到“直接修改”；如果反复出现修改提案，请先检查当前模式。

建议先用文件副本试一个小任务。设置中可以添加自定义指令，也可以导入自己的 skill 文件、文件夹或 ZIP。

## 数据与卸载

API Key 和设置保存在本机，未使用系统密钥库加密。提交给 AI 的文档内容会发送到所选模型服务；启用联网搜索时，搜索请求会发送到对应服务。

卸载时打开“卸载 Trojan AI for Office”，完成后将对应应用移到废纸篓。卸载保留本机设置与历史。
