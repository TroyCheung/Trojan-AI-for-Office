# Trojan AI for Office

**让 Agent 帮忙做事，把表达的判断留给人。**

我个人用下来，体验是怎样的呢？

如果把一整套内容交给 AI，让它直接做完 PPT 或写完文章，最后的结果往往和我想的有些距离。可能是模型还不够聪明，也可能是 harness 的设计、我给的提示还不够完善。

所以我想换一种做法：在 Office 里一边做、一边看，让 Agent 帮忙读取、整理和修改，我来判断方向和结果。先改一段、看一页，觉得合适再往下做。对我来说，这样更容易控制，也更接近日常工作的习惯。这就是我做 Trojan AI for Office 的原因。

（我接触的一些插件需要单独订阅，所以也想把这个插件免费分享出来，让大家接上自己的 API，在 Office 里用起来，也能有一个不错的 Agentic 工作体验。模型调用的费用由各自选择的服务收取。）

## 同一个助手，接着三种工作往下做

| 你正在做的事 | 可以怎样开始 | 保留什么 |
| --- | --- | --- |
| **Word：把表达改到位** | “把这段说清楚，保留我的原意，先给修改建议。” | 原文上下文、必要事实与现有格式 |
| **PowerPoint：让重点看得出来** | “这页主次不清，按内容关系重新安排。” | 内容含义、必要关系与当前品牌规范 |
| **Excel：把数据和公式核对清楚** | “检查这块区域的公式，告诉我哪里需要改。” | 数据范围、公式依赖与已有内容 |

工具能力会随 Office 版本有所不同；模型接口、所选模型与文件复杂程度也会影响结果。

## 建议落到具体位置，修改留给你决定

![工作流程示意：指定范围、读取上下文、提出可核对的修改、用户审核、写回并复检](docs/images/review-flow.svg)

**默认“审核后修改”**：内容覆盖等需要确认的操作先给出修改提案，你可以采用或拒绝。“只读建议”适合先判断方向；“直接修改”适合你已经明确要执行的任务。部分低影响格式操作和空白位置写入可直接执行。聊天中说“直接改吧”不会自动切换模式，需要在界面中切换。

## 自带一点工作章法，给你的方法留出空间

这里保留了从真实工作需求中整理出的少量基础指引：

- **先明确范围，再动手。** 围绕你指定的段落、页面或单元格工作，关键缺口才询问。
- **结论有依据，修改有来由。** 保留事实和原意，区分已确认信息与待核实内容。
- **表达与排版服务于内容。** 文字照顾上下文，幻灯片按观点和支撑安排主次，表格留意公式与数据关系。
- **做完再核对。** 区分已完成、部分完成和无法验证，避免把工具调用成功当成任务已经完成。

这些规则提供一个有条理的起点。你可以在设置中填写自己的指令，或导入自己的 skill 文件、文件夹和 ZIP，补充文风、行业方法和交付标准。

## 记住工作习惯，也能用上自己的工作流

这是我比较想分享的两个功能：

- **Memory：跨会话记忆。** 开启后，Agent 可以保存工作中的偏好和规则，供后续对话使用。你可以在设置里查看、删除记忆，也可以关闭这个功能。
- **Skills：加入自己的工作流。** 把常用的写作要求、处理步骤或行业方法放进 skill，导入后让 Agent 在工作时参考，不用每次从头说明。

在我自己用过的 Office 插件里，这样的组合还不常见。我希望它能逐渐适应每个人的工作方式。
